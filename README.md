# 📖 Overview

Directional audio has revolutionized how sound can be delivered to a specific location without disturbing the surrounding environment. However, most commercially available parametric speakers project sound in a fixed direction and cannot adapt when the listener moves.

This project introduces a **software-defined proof-of-concept** for an **AI-assisted dynamic ultrasonic beam steering system** capable of continuously tracking a moving target and steering a focused acoustic beam toward it in real time.

Developed as part of our **Signal Processing Applications using MATLAB (24ECE146)** course, this project combines concepts from **Signal Processing, Acoustics, Physics, Mathematics, Scientific Computing, and Software Engineering** to demonstrate the feasibility of adaptive directional sound delivery through simulation.

Rather than mechanically rotating a speaker, the system electronically steers the acoustic beam by continuously recalculating the phase delay of each ultrasonic transducer in a virtual phased array.

# ⚙ Key Features

## 🎯 Dynamic Target Tracking

Simulates a moving human target inside a virtual 3D environment while continuously updating the beam direction in real time.

---

## 🔊 Intelligent Beam Steering

Implements Delay-and-Sum beamforming by dynamically adjusting the phase of each ultrasonic transducer to focus acoustic energy toward the target.

---

## 🌊 Acoustic Wave Simulation

Models constructive and destructive interference to create a narrow, highly directional acoustic beam.

---

## 📊 Real-Time Visualization

Displays:

- Ultrasonic Phased Array
- Moving Target
- Steering Direction
- Acoustic Pressure Distribution
- 3D Beam Intensity
